# Alea Brand Direction (Phase 1)

This branding direction is inspired by the Alea Connect positioning around:

- Connettivita
- Sicurezza
- Innovazione

## Visual translation

- Primary color: deep trust blue for enterprise reliability.
- Accent color: cyan for modern technology and cloud services.
- Header and navigation: darker blue emphasis for professional B2B perception.
- Product naming: Alea Connect across shell-level UI labels.

## Phase 1 scope

- Default color tokens in global style layer.
- Sidebar and core shell labels.
- Package metadata and distribution naming.

## Next steps

- Replace favicon and icon pack with Alea assets.
- Update login and onboarding visual surfaces.
- Add role-aware landing for Home and Business editions.
